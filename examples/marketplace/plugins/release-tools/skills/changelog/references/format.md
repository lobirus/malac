# Changelog format

Follow [Keep a Changelog](https://keepachangelog.com/en/1.1.0/):

- One `## [version] - YYYY-MM-DD` heading per release, newest first.
- Group entries under `### Added`, `### Changed`, `### Fixed`, `### Removed`, in that order; skip empty groups.
- One line per change, starting with a verb, written for the people who use the project.
